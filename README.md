# React Practic

Frontend + Backend alag-alag folders me:

```
├── frontend/   # React + Vite app
└── backend/    # Express API server
```

## Frontend chalane ke liye

```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173

## Backend chalane ke liye

```bash
cd backend
npm install
npm run dev
```
Backend: http://localhost:5000
